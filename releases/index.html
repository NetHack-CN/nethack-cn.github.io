如何选择版本

1. 选择操作系统和CPU架构

文件名片段说明
win-x64 / .zipWindows 64位
linux-amd64Linux 64位
linux-i386Linux 32位
linux-arm64Linux ARM64
macos-arm64macOS Apple Silicon芯片
NetHack-cn-src-*源代码包

2. Linux用户：选择glibc还是static

变体说明
glibc体积更小，但运行时系统需要已安装ncurses库（多数发行版自带）
static解压即玩。如果在glibc版本上遇到库缺失或版本不兼容问题，请选这个

3. 选择汉字规范（文件名结尾的 -s / -t / -tg / -twp）

后缀规范
-s简体（原文，该项目的单一事实来源，开发时使用的正字法）
-tOpenCC 标准繁体
-tg通用规范繁体（脚本：amorphobia/opencc-tonggui）
-twp台湾繁体（同时转换词汇）

（除s外其他正字法版本都由OpenCC进行自动转换得到，脚本本身具有局限性，以及源代码里也可能存在词汇不按一般人认知的词汇边界切割，因此不保证没有错误写法。）
注意：在哪种正字法的版本，查询/许愿/灭绝就用哪种正字法的汉字。（应该没有人像某个老酒鬼一样一个字写新字体另一个字写旧字体吧，应该……）
